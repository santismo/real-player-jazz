# François Leduc Guitar Dataset studies

Audio and performance-aligned MIDI: Xavier Riley, Drew Edwards, Simon Dixon,
High Resolution Guitar Transcription Via Domain Adaptation (ICASSP 2024).
Original transcriptions: François Leduc.
https://huggingface.co/datasets/xavriley/FrancoisLeducGuitarDataset
Snapshot: a38306c244b3ea81496ad58b4514622185e58211
The current Hugging Face release declares MIT. Earlier Zenodo releases had different research-only terms; the downloadable HF release is the source here.

Local MIDI and published syncpoints are converted into performance note and bar
JSON. Original audio streams directly from the same dataset. No YouTube match
is claimed for these audio-only renditions. Note times are already in recording
seconds, so both ends of a note, tab playhead and fretboard use the media clock.
Chords were not supplied and are not fabricated. Fingering is suggested by the
app, not a claim of the performer's exact string choices. Listed renditions by
other guitarists do not count toward the requested 50 Joe Pass/Django goal.
